# Afro Store Storefront Documentation

This directory contains documentation for the Afro Store storefront implementation.

## 📁 Directory Structure

```
docs/
├── README.md                    # This file - documentation index
├── features/                    # Feature documentation and guides
│   └── collections.md          # Collections feature guide
├── setup/                       # Setup and configuration guides
├── api/                         # API integration documentation
└── deployment/                  # Deployment guides
```

## 📚 Documentation Categories

### **features/** - Feature Implementation Guides
Documentation for specific features, enhancements, and functionality:
- How-to guides for implementing features
- Feature comparisons and recommendations
- Best practices for specific features

### **setup/** - Setup & Configuration
Initial setup, configuration, and environment setup guides:
- Environment variables
- Development environment setup
- Third-party integrations setup

### **api/** - API Integration
API integration documentation and examples:
- Backend API usage
- External service integrations
- Authentication and authorization

### **deployment/** - Deployment Guides
Production deployment and hosting documentation:
- Deployment workflows
- Environment-specific configurations
- Performance optimization

## 🎯 Adding New Documentation

When adding new documentation:

1. **Choose the right category** based on content type
2. **Use clear, descriptive filenames** (kebab-case: `my-feature.md`)
3. **Include these sections**:
   - Overview/Purpose
   - When to use/not use
   - Implementation steps (if applicable)
   - Examples
   - Related resources

4. **Update this README** with a link to your new doc
